# ЭХО-7

Текстовый sci-fi хоррор-квест в браузере. Станция молчит одиннадцать суток. Ты проснулся не по расписанию. Они реагируют на звук, так что не шуми.

**Играть:** https://ferid1b.github.io/echo7/

- 45 сцен и 12 концовок
- Здоровье, рассудок, кислород, инвентарь
- Три пути прохождения: шаттл, сигнал бедствия, перегрузка реактора
- Автосохранение, управление кнопками или цифрами 1–9

Вся игра — один файл `index.html`, без зависимостей и сборки.

**Оффлайн и приложение (Android):** открой сайт в Chrome, подожди пару секунд, затем меню ⋮ → «Установить приложение». Игра появится на экране телефона и будет работать без интернета. Шрифты лежат в `fonts/`, оффлайн-кэш — `sw.js`.
